# ⚡ PhonePe Pulse: Payment Insights Dashboard

A dynamic, interactive Power BI analytics dashboard designed to analyze digital payment transactions, user growth trends, demographics, and service adoption across India’s digital payments ecosystem.

---

## 💳 Project Title / Headline

**PhonePe Pulse: Digital Payments & User Growth Analytics Dashboard**  
An interactive reporting solution built to evaluate transaction volumes, total value, demographic segments, day-type usage, and service category performance across the PhonePe ecosystem.

---

## 📌 Short Description / Purpose

The **PhonePe Analytics Dashboard** provides real-time visibility into digital transaction dynamics, tracking **300K total transactions** valued at **₹3.47Bn**. Designed for fintech strategists, product managers, and growth analysts, this dashboard highlights month-over-month (MoM) growth, demographic engagement, peak usage periods, and high-value service categories to drive operational decision-making.

---

## 📂 Tech Stack

* **Power BI Desktop** – Report wireframing, custom visual formatting, and interactive dashboard creation
* **Power Query** – Data extraction, cleansing, data type transformation, and structural mapping
* **DAX (Data Analysis Expressions)** – Time intelligence (MoM Growth calculations), dynamic KPI aggregations, user contribution metrics, and visual conditional logic
* **Data Modeling** – Star Schema establishing relationships between transactional fact tables and user demographic/calendar dimension tables
* **File Format** – `.pbix` (Power BI Report File) & High-Resolution Preview Images

---

## 📊 Dashboard Structure & Features

### 📌 Primary KPIs (Top Header)
* **Total Transactions:** **300K** total transactions processed (**+8.97% MoM Growth**).
* **Total Value:** **₹3.47Bn** total transaction value (**+8.98% MoM Growth**).
* **Unique Users:** **96.00%** customer engagement/adoption rate.
* **Successful Rate:** **107.66K** successful transactions logged with interactive trendlines.
* **Header Slicers:** Interactive filters for **Month** selection and **Payment Status** (*Failed*, *Pending*, *Successful*).

---

### 📌 Visual Analytics Breakdown

#### **1. Transactions Over Time (Dual-Axis Line Chart)**
* Tracks monthly fluctuations across **Total Transaction Volume** and **Total Transaction Value** from Jan to Dec, identifying seasonal demand peaks (e.g., July peak).

#### **2. Age Segment Contribution (Donut Chart)**
* Analyzes user adoption across age demographics:
  * **Gen X:** **37.58%**
  * **Millennials:** **37.07%**
  * **Gen Z:** **20.78%**
  * **Boomers:** **4.57%**

#### **3. Service Transaction Value Analysis (Horizontal Bar Chart)**
* Measures monetary throughput across service lines, highlighting **Loans ($2532.51M)** as the top contributor, followed by **Insurance ($512.92M)**, **Money Transfer ($378.19M)**, and **Recharge Bills ($50.69M)**.

#### **4. Top 5 Users by Transaction Value (Column Chart)**
* Identifies high-value individual account holders (*Michael Smith*, *Jennifer Williams*, etc.) to monitor whale transaction activity.

#### **5. Weekday vs Weekend Usage (Donut Chart)**
* Highlights transaction behavior split across **Weekdays (71.6%)** vs. **Weekends (28.4%)**.

---

## 📈 Business Impact & Insights Summary

By evaluating digital payment trends, product leadership can optimize platform reliability during high-activity **Weekday periods (71.6% of overall traffic)**. Marketing and credit risk teams can prioritize financial products—such as **Loans**, which yield the highest overall transaction value— targeting **Gen X (37.58%)** and **Millennials (37.07%)**, who together represent over 74% of the active platform user base.
